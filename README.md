# VisionWell MVP - AI 관상 & 수상 분석기

AI를 활용한 실시간 안면 및 손금 분석 애플리케이션입니다.

## 🚀 주요 기능

- **실시간 감정 및 나이 예측**: MediaPipe와 DeepFace를 활용하여 실시간으로 얼굴을 분석합니다.
- **관상학 분석 (Physiognomy)**: 초기, 중기, 말년운 및 눈, 코, 입의 특징을 분석하여 상세한 관상 정보를 제공합니다.
- **수상학 분석 (Palmistry)**: 손바닥의 형태와 주요 선(생명선, 두뇌선, 감정선 등)을 감지하여 성향 및 운세를 분석합니다.
- **다국어 지원**: 분석 결과를 한글로 표시하며, 가독성 높은 UI를 제공합니다.

## 🛠️ 설치 및 설정

### 1. 전제 조건
- Python 3.8 이상 (권장: 3.11)
- 웹캠 (실시간 분석용)

### 2. 가상환경 구축 및 의존성 설치
```bash
# 가상환경 생성 (권장)
python -m venv venv

# 가상환경 활성화 (Windows)
.\venv\Scripts\activate

# 의존성 설치
pip install -r requirements.txt
```

### 3. 필요한 모델 파일
애플리케이션 실행을 위해 다음 파일들이 프로젝트 루트 디렉토리에 있어야 합니다:
- `face_landmarker.task`
- `hand_landmarker.task`

(이 파일들은 MediaPipe 공식 문서에서 다운로드할 수 있습니다.)

## 🏃 실행 방법

`runner.py` 또는 `app.py`를 직접 실행할 수 있습니다.

```bash
python runner.py
```

또는

```bash
python app.py
```

## 🎥 사용 방법

1. 프로그램이 실행되면 카메라 화면이 나타납니다.
2. **관상 모드 (Face)**: 화면 상단의 버튼들을 클릭하여 부위별 상세 관상을 확인하세요. 실시간 감정과 예측 나이도 표시됩니다.
3. **수상 모드 (Hand)**: 화면 왼쪽 상단의 [수상학/관상학] 전환 버튼을 클릭하여 수상 모드로 변경한 뒤, 손바닥을 카메라에 정면으로 비춰주세요.
4. **종료**: 키보드의 `q`를 눌러 프로그램을 종료합니다.

## ⚠️ 주의사항
